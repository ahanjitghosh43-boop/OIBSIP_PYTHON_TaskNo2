# BMI Calculator

A GUI-based BMI Calculator developed using Python and Tkinter.

## Features

- Calculate BMI using weight and height
- BMI category detection
- Input validation
- SQLite database storage
- Multi-user support
- View BMI history
- Search user records
- BMI trend graph using Matplotlib
- Export records to CSV
- Clear all database records

## Technologies Used

- Python
- Tkinter
- SQLite3
- Matplotlib

## BMI Categories

| BMI Range | Category |
|------------|-----------|
| Below 18.5 | Underweight |
| 18.5 - 24.9 | Normal |
| 25.0 - 29.9 | Overweight |
| 30 and Above | Obese |

## How to Run

Install matplotlib:

```bash
pip install matplotlib
```bash
python main.py
